## The objection at full strength

Respect for an animal means not wasting it. Indigenous and traditional cultures used every part, and modern industry using the hide is following that tradition. It would be more disrespectful to throw it away.

## Response

Not wasting things is a good value, and nothing here asks you to waste what already exists. If an animal has died, using the hide is better than burying it.

The argument only works once the killing has been taken for granted. It asks whether to use a hide that already exists, not whether to kill the animal for the meat. If the killing is not justified, then the rest follows from that mistake, however thriftily the leftovers are handled. A thrifty use of something that should not have happened is still not a reason for it to have happened.

On traditions of using every part, the argument for cultures that depend on hunting to live is a different case, covered at [What about Inuit and other Indigenous peoples?](/a/indigenous-peoples/). That is not the situation of someone choosing a handbag in a shop.

## In short

- Avoiding waste is good, but it assumes the killing is already settled.
- The argument is about the leftovers, not whether the animal should have been killed.
- For traditional subsistence, see [What about Inuit and other Indigenous peoples?](/a/indigenous-peoples/).
